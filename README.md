# 🎓 Student Management System (SMS)

A web-based **Student Management System (SMS)** designed to manage student information, registration, profiles, verification, and student records through a simple and user-friendly interface.

## 📌 Project Overview

The **Student Management System (SMS)** is a web application developed to organize and manage student information in one place.

The system provides an interface for registering student profiles, maintaining student details, verifying submitted information, and viewing student records.

The project is developed using **HTML, CSS, JavaScript, and LocalStorage**.

## 🎯 Objectives

* To maintain student information in an organized manner.
* To provide an easy student registration system.
* To manage student profile information.
* To support student information verification.
* To provide a simple and responsive user interface.
* To reduce manual management of student records.

## ✨ Features

### 🔐 Login System

Provides a login interface for accessing the system.

### 📊 Dashboard

The dashboard provides an overview of student records and system statistics.

### 👤 Student Profile Registry

The system can collect student information such as:

* Full Name
* Graduation/Batch Year
* Company or Organization
* Mobile Contact Number
* Professional/Student Email
* Username

### ✅ Verification System

Submitted student information can be reviewed and verified.

The verification section provides:

* Student Name
* Batch
* Organization
* Contact Details
* Verification Status
* Available Actions

### 📖 Student Directory

The directory allows users to view and search student records.

Students can be searched using information such as:

* Name
* Company/Organization
